# 店舗に確認したいこと

サイトは、確かめられた情報だけで作ってあります。
下の項目は、分かったら `data/site.ts`・`data/menu.ts` に値を入れてください。
値が `null`（空）の項目は、画面にも構造化データにも出ません。入れると、自動で出ます。

## 1. 公開の前に確かめたいこと

| 確認したいこと | いまの扱い | 入れる場所 |
| --- | --- | --- |
| **電話番号 070-2010-6803 をサイトに載せてよいか** | Google マップと食べログに載っている番号を載せている。載せないなら `phone: null` にする（全ページと構造化データから消える） | `data/site.ts` の `phone` |
| **店名の正式な書き方** | 看板と Instagram の表示名に合わせて「Cafe Re faire」。Google マップとハッシュタグは「Cafe Refaire」（空白なし）。両方を同じ店として伝える設定にしてある | `data/site.ts` の `name` / `alternateNames` |
| **本番のドメイン** | 未定。決まったら Vercel の `NEXT_PUBLIC_SITE_URL` に入れる（入れるまで、検索エンジンには載らない） | Vercel の環境変数 |
| **写真の掲載の可否** | 届いた34枚のうち28枚を使用。子どもが写っている1枚は、子どもの部分を切り落として表札とオリーブだけにしてある | `scripts/prepare-images.mjs` |

| 項目 | メモ | 入れる場所 |
| --- | --- | --- |

## 3. 毎月の作業

- **その月の営業日**（不定休・時間の変更・出店）を `data/site.ts` の `monthNotices` に足す。
  アクセスのページの「営業日」と、構造化データ（その日だけの営業時間）に出ます。過ぎた月は、自動で画面から消えます。
- お知らせを載せるときは、`content/blog/<年>/<日付>-<名前>.md` を `category: "news"` で足す
  （ひな形は `content/blog/_template-news.md`）。

## 4. 写真について

- 届いた写真は LINE のアルバムから保存したもので、長辺が 1,400〜1,700px です。
  2026年10月の改修で、写真を画面いっぱいに使う組み方にしました。そのため、トップの最初の画面（ケーキの写真）は、
  iPhone のような画素の細かい画面や、大きなモニターでは、1.5〜1.8倍に引き伸ばして表示されます（少し甘く見えます）。
  **元のデータ（スマートフォンから直接取り出した写真）があれば、差し替えるだけでくっきりします。**
  とくに、最初の画面に使っている抹茶テリーヌ（横長の画面）とティラミスムース（縦長の画面）の2枚。
- トップの最初の画面の写真は、いまはケーキです。店内や外観の写真にしたいときは、`components/sections/Hero.tsx` の2行を替えます
  （横長の画面＝PC・横にしたタブレットには横位置、縦長の画面＝スマートフォン・縦に持ったタブレットには縦位置の写真）。
  替えたあとは、白い店名が写真の明るいところに重なっていないかを、PC とスマートフォンの両方で確かめてください。
- 記事の見出し写真（`eyecatch`）に縦位置の写真を選ぶと、縦長の枠で小さめに出ます（横長の枠に入れると、大きく切れてぼやけるため）。
- ほしい写真：飲みもの、曜日プレートの残りの曜日、黒蜜抹茶わらび餅、店の外観を道路の側から撮ったもの、
  晴れた日の外観、席から見た窓。
